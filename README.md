# 记账 (ji-zhang)

老师经费记账本：一个网页应用，专门记录老师给的经费和帮老师花的钱。每笔账有日期、类别、金额和用途说明，还能贴照片当凭证。

## 功能

- 记账：收入（老师拨款）和支出，金额、类别、日期、用途说明
- 照片凭证：每笔账最多贴 9 张照片，列表里看缩略图，点开看大图
- 汇总：剩余 / 老师共给 / 已支出，超支时提示；按月查看，分类统计
- 导出 PDF 账单：月度账单和年度账单，明细表在前、照片凭证在后；同一笔账的几张照片共用一个凭证号、理由只写一次
- 每笔账都可以修改和删除

## 技术栈

- Bun 1.3.10 + React 19 + TypeScript
- drizzle-orm + SQLite（数据存在本地）
- Tailwind CSS、recharts、zod

## 运行

这是 Muse 空间（Space）的源代码，需要在 Muse 的 Space 运行环境中使用，在 Muse 之外不能直接跑起来，因为它依赖 Muse 提供的 `@hatch/space-sdk`（`package.json` 里的本地文件依赖）。

常用命令：

```bash
bun run typecheck  # 类型检查
bun run build      # 构建前后端
```

账本数据和照片凭证存在本地，不在这个仓库里。这里只有源代码。
